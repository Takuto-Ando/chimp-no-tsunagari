# 動物のつながり — 公開研究デモ

3本のChimpACT公開サンプルと事前計算済み推定結果で、動物の共起・関係可視化を検証する非商用研究デモです。AIライブ推論ではありません。社会関係は架空の設定であり、確認済みの個体関係ではありません。
